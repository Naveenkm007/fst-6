# Contently CMS Dashboard

Frontend-only CMS dashboard demo for `naveenkm07` (`1NH24CS409`).

## Repository

[GitHub repository](https://github.com/Naveenkm007/fst-6)

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL to view the dashboard. The app uses mock data, React state, and `localStorage`; it does not use a backend or external database.
